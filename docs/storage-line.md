# Personal storage boundary

Drive remains a provider-specific transport. Its complete pinned method
surface, OAuth refresh state, ranged ZIP inventory, restartable byte download
and server-side copy do not define a personal corpus format.

IB owns retained source identity and corpus views. The surviving Pensieve line
extends Cauldron with exact bytes, explicit source/corpus, provider object and
generation, ZIP-member locator and per-source privacy/model policy. Derived
conversation nodes, history records, text and indexes reference those sources.
See [IB retained-source ingestion](https://github.com/isomorphisms/ib/blob/0.2/pensieve-arxiv/docs/retained-source-ingestion.md).

The authenticated 7,754,047,385-byte Takeout inventory/member extraction is
historical live transport evidence. It is not an OpenAI conversation source.
The authorized account's standard OpenAI export was absent at that observation.
`tests/live-find-chatgpt-export.sh` still distinguishes absence from transport
failure. Its decoder fixtures cannot satisfy that missing live-source stage.
The selective extraction code currently lives in live test harnesses, including
an inherited Python decompressor. It is not yet an installed Grease product
extractor, and it needs provider-version fencing and a retained verification
handoff before personal-corpus acquisition can be called integrated.

SDF raw archival fixes `[0,T)` before transfer, streams bounded ranges through
OpenSSH, and preserves private resumable state. Completion now requires a
provider SHA-256 matching the source hash; source pre/post hashing alone cannot
rule out transient in-place edits during payload transfer. Missing provider
checksum is an unverified completed upload, never exact-byte acceptance.
Completed receipts are bound to source target/path and destination/session
parameters before cache reuse. Raw archival never invokes parsing/refiling.
[mbox](https://github.com/isomorphisms/mbox) preserves raw occurrence byte ranges;
SPEC-LIST filing and live delivery-lock qualification remain later work.

Remaining SDF gates include actual NetBSD utility/SSH/source identity,
cluster-node continuity and delivery behavior, narrow Drive write authorization,
the real transfer and readback receipt. An interrupted remote stat/read sequence
is not a qualified immutable SDF snapshot. No physical mailbox was read here.

The former ARMv7 artifact used a generic Linux cross compiler. The current
[Android bundle producer](android-client-build.md) replaces it with distinct
NDK/Bionic helper bundles and keeps installed/runtime evidence NOT_RUN.
Historical Linux build evidence is not Android delivery. Cat Food issue 117 owns
package/helper acquisition and exact target qualification; no phone compilation.

Android authorization is a platform adapter in IB, not an ABI-specific port.
Package identity remains `org.isomorphisms.ib.webview`. Live OAuth needs one
stable private signer, its Android client SHA-1 registration, matching Web
client, enabled Drive API/consent configuration, and actual Google Play services
authorization on C67. Public test/runner-local signers do not satisfy that gate.

Cat Food owns deployment facts; Kitchen owns user procedures; Flexible Pipes
owns repeatable execution; AICI owns receipt acceptance. Keep private payloads,
credential files, session capability URIs and OAuth results out of repository
and ordinary pipeline artifacts.
